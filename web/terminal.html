webTOS — an interactive Linux shell, on a terminal, in this tab

BusyBox sh runs on a pseudoterminal inside the wasm Linux runtime: it sees a real tty, echoes what you type, forks and execs commands, and repaints when you resize this window. Try ls -l /bin, vi /root/notes.txt (a full-screen editor — :q! to leave), echo hi > /root/f && cat /root/f. One-shot command demo →

The guest has no network. To grant one, run the relay (node tools/webtos_gateway.mjs --allow HOST:PORT) and reload with ?gateway=ws://127.0.0.1:8081. Nothing is reachable unless the relay's own allowlist names it.

vendor/xterm is missing. Run tools/fetch_xterm.sh to fetch the pinned terminal emulator, then reload.
