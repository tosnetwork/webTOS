webTOS — BusyBox on a Linux x86-64 runtime, locally in your browser

A static musl BusyBox binary is executed instruction-by-instruction by the webTOS x64-engine + linux-compat stack (wasm) in a Web Worker. The filesystem is in-memory and persists across commands. Try: echo hello, ls /, mkdir /tmp/a, sh -c 'echo hi > /tmp/x && ls /tmp', cat /etc/motd.
